# Как выложить LUCKY 777 в интернет и открыть в Telegram

Инструкция для человека, который ни разу не заливал сайт на хостинг. Нужны только браузер, аккаунт GitHub и Telegram. Терминал не обязателен.

**Что получится:** сайт будет жить по адресу вида
`https://твой-логин.github.io/lucky777/`
Это обычный HTTPS-адрес — именно такой требует Telegram для мини-апп.

---

## Шаг 1. Выложить файлы на GitHub

### Вариант А — GitHub Desktop (проще всего, рекомендую)

1. Скачай и установи **GitHub Desktop**: https://desktop.github.com
2. Открой его и войди в свой аккаунт GitHub (кнопка **Sign in to GitHub.com**).
3. В меню сверху: **File → Add Local Repository…**
4. Выбери папку проекта:
   `/Users/daniilsavenkov/Documents/deepseek-harness/default-workspace/lucky777`
5. Папка уже инициализирована как git-репозиторий, поэтому GitHub Desktop сразу покажет список файлов. Если он всё же предложит **create a repository** — согласись, имя `lucky777`.
6. В поле **Summary** напиши `LUCKY 777 v1.0` и нажми **Commit to main**.
7. Сверху нажми **Publish repository**.
   - **Обязательно сними галочку «Keep this code private»** — бесплатный GitHub Pages работает только у публичных репозиториев.
   - Нажми **Publish Repository**.

Готово: файлы уехали на GitHub.

### Вариант Б — без установки, через сайт GitHub

1. Зайди на https://github.com → **New repository**.
2. **Repository name:** `lucky777`, тип **Public**, нажми **Create repository**.
3. На странице пустого репозитория нажми **uploading an existing file**.
4. Перетащи в окно **содержимое** папки `lucky777`:
   `index.html`, папки `css`, `js`, файлы `.nojekyll`, `server.py` и т.д.
   ⚠️ Важно: перетаскивай именно файлы и папки, а не саму папку `lucky777` — иначе `index.html` окажется внутри лишней папки и сайт не откроется по короткому адресу.
5. Внизу нажми **Commit changes**.

### Вариант В — терминал (если хочется)

```bash
cd /Users/daniilsavenkov/Documents/deepseek-harness/default-workspace/lucky777
git init
git add .
git commit -m "LUCKY 777 v1.0"
git branch -M main
git remote add origin https://github.com/ТВОЙ_ЛОГИН/lucky777.git
git push -u origin main
```

Для пуша GitHub попросит логин и **Personal Access Token** (Settings → Developer settings → Personal access tokens → Fine-grained tokens, доступ к репозиторию `lucky777`). Пароль от аккаунта не подойдёт.

## Шаг 2. Включить GitHub Pages

1. Открой страницу своего репозитория на github.com.
2. Сверху выбери вкладку **Settings**.
3. В левом меню — **Pages**.
4. В блоке **Build and deployment**:
   - **Source:** `Deploy from a branch`
   - **Branch:** `main`
   - **Folder:** `/ (root)`
5. Нажми **Save**.
6. Подожди 1–3 минуты и обнови страницу. Сверху появится ссылка:
   `https://ТВОЙ_ЛОГИН.github.io/lucky777/`

Открой её в браузере — должна запуститься LUCKY 777. Если 404 — подожди ещё пару минут и обнови; первый деплой бывает медленным.

Проверь, что в репозитории `index.html` лежит **в корне**, а рядом папки `css` и `js`. Если `index.html` оказался внутри `lucky777/`, адрес будет длиннее: `https://ЛОГИН.github.io/lucky777/lucky777/` — тогда просто используй этот адрес.

## Шаг 3. Создать мини-аппу в Telegram

Тебе нужен бот. Если его ещё нет:

1. Открой в Telegram **@BotFather**.
2. Отправь `/newbot`.
3. Придумай имя (например, `LUCKY 777`) и username, заканчивающийся на `bot` (например, `lucky777luckybot`).
4. BotFather пришлёт **токен** вида `123456:AA...`. Никому его не показывай и не выкладывай на GitHub — для этого шага он вообще не нужен.
5. По желанию поставь аватар бота: `/setuserpic` → выбери бота → отправь `bot/logo-512.png`.

Теперь сама мини-аппа:

6. В @BotFather отправь `/newapp`.
7. Выбери своего бота из списка.
8. **Title:** `LUCKY 777`
9. **Short description:** `Слоты, рулетка, блэкджек, краш, кости и кено на виртуальные очки. Бонусы каждый день. 18+`
10. **Photo:** отправь файл `bot/app-photo.png` из проекта (это готовый баннер 640×360). Если BotFather разрешает пропустить — можно `/empty`.
11. **Web App URL:** вставь адрес из Шага 2, обязательно с `https://` и слешем на конце:
    `https://ТВОЙ_ЛОГИН.github.io/lucky777/`
12. **Short name:** `lucky777` (латиница, без пробелов).
13. Готово. BotFather даст ссылку вида:
    `https://t.me/ТВОЙ_БОТ/lucky777`

Открой эту ссылку на телефоне — мини-аппа должна открыться внутри Telegram.

### Включить реферальные ссылки

Пока в `js/config.js` пустой `botUsername`, кнопка «Пригласить» ведёт на сайт, а не в мини-аппу. После создания бота открой `js/config.js` (на GitHub — карандашом) и впиши:

```js
window.LUCKY_CONFIG = {
  botUsername: 'ТВОЙ_БОТ_БЕЗ_@',   // например: lucky777_points_bot
  appShortName: 'lucky777',
  // остальное не трогай
};
```

Сохрани → **Commit changes**. Через минуту приглашения начнут открывать мини-аппу.

**Как работает рефералка:** друг открывает ссылку → получает +2 000 и кнопку «Отправить другу бонус» → тебе приходит сообщение со ссылкой → открываешь → +1 000. Без сервера, лимит 50 друзей, ссылка живёт 30 дней.

### Кнопка меню (по желанию)

Чтобы приложение открывалось кнопкой внизу чата:

1. В @BotFather отправь `/setmenubutton`.
2. Выбери бота.
3. Отправь URL мини-аппы.
4. Отправь текст кнопки: `Играть`.

## Важно понимать

- **Токен бота не нужен для работы мини-аппы.** Приложение — это статический сайт; Telegram просто открывает URL. Код бота (`bot/bot.py`) нужен только если ты хочешь, чтобы бот отвечал на `/start`. Для этого его надо отдельно hosting'ить на Railway/Render/Fly.io — это следующий этап, не обязательный.
- **Данные хранятся на устройстве игрока** (localStorage) и в Telegram CloudStorage. Общего сервера и базы нет: у каждого свой прогресс.
- **Изменил файлы → сделай commit/push.** GitHub Pages пересоберёт сайт за минуту. Telegram может закешировать старую версию — закрой мини-аппу и открой заново.
- **Приватный репозиторий** не подойдёт для бесплатного Pages — репозиторий должен быть публичным.
- Если `github.io` не открывается у тебя или у друзей (бывает из-за блокировок), альтернатива — **Cloudflare Pages**: там можно загрузить папку или zip и тоже получить HTTPS-адрес.

## Если что-то не работает

| Симптом | Что проверить |
|---|---|
| 404 на `github.io` | Прошло меньше 3 минут? Ветка `main`? Папка `/ (root)`? `index.html` в корне? |
| Страница пустая / нет стилей | Открой консоль браузера (F12 / Develop → Show JavaScript Console). Часто причина — файлы залиты внутрь лишней папки и путь не совпадает. |
| Telegram пишет «Web App URL is invalid» | URL должен начинаться с `https://`, без `localhost` и без пробелов. |
| Открывается старая версия | Закрой мини-аппу, очисти кеш Telegram (Настройки → Данные и память) или добавь `?v=2` к URL в BotFather. |
| Не открывается у друзей | Проверь, что репозиторий публичный, а ссылка — с `https`. |

## Что заливать

Обязательно: `index.html`, `css/`, `js/`, `.nojekyll`.
Можно не заливать: `shots/` (скриншоты для README), `tools/`, `bot/`, `server.py` — сайту они не нужны, но и не мешают. Секретов в них нет.
