# Бэкенд LUCKY 777 на Supabase

Бот в чате и общий прогресс на разных устройствах невозможны на GitHub Pages: нужен сервер и база. Выбран **Supabase** — бесплатный Postgres + Edge Functions + dashboard.

## Что это даст

- Баланс, уровень и XP хранятся в Postgres по `telegram_id`, а не только в телефоне.
- Бот в группе: `/me` — уровень и баланс, `/top` — топ игроков этого чата, `/help`.
- При добавлении бота в чат — приветствие с командами.
- Мини-аппа синхронизирует состояние после каждого раунда и подтягивает его на новом устройстве.
- Топ в чате — только среди тех, кто зарегистрировался (`/me` или открыл мини-аппу из чата). Telegram не даёт боту список всех участников.

## Что нужно сделать тебе

1. Зарегистрироваться на https://supabase.com и создать проект (Free, регион EU).
2. Открыть **SQL Editor** и выполнить `backend/schema.sql`.
3. Прислать мне:
   - **Project URL** (`https://xxxx.supabase.co`);
   - **anon public key** (он публичный, не секрет).
4. **Не присылать в чат**:
   - `service_role` key;
   - токен бота.
   Их положим в секреты Supabase отдельно.
5. Разрешить деплой Edge Function (через Supabase CLI или Dashboard). Если CLI — понадобится `supabase login` под твоим аккаунтом.

Уже лежат в проекте:
- `supabase/functions/telegram/index.ts` — вебхук (`/me`, `/top`, приветствие);
- клиентская синхронизация `js/core/backend.js` + `supabaseUrl`/`supabaseAnonKey` в `js/config.js`;
- схема и инструкция `supabase/README.md`.

Осталось: создать проект, выполнить SQL, задеплоить функцию и указать URL/anon key.

## План таблиц

- `players` — Telegram ID, имя, уровень, XP, баланс, сбросы.
- `chat_players` — в каких чатах игрок зарегистрирован (для `/top`).
- `chat_settings` — название чата и служебные настройки.

Схема уже лежит в `backend/schema.sql`, инструкция по деплою бота — в `supabase/README.md`.

## Команды бота

| Команда | Что делает |
|---|---|
| `/me` | Показывает уровень, баланс и прогресс; регистрирует игрока в этом чате |
| `/top` | Топ-10 игроков чата по уровню, затем по балансу |
| `/help` | Короткая справка и ссылка на мини-аппу |
| добавление в чат | Приветствие и список команд |

## Безопасность

- Edge Function работает с `service_role`, RLS закрывает прямой доступ.
- Мини-аппа шлёт `initData`; функция проверяет подпись HMAC с токеном бота.
- Баланс в этой версии синхронизируется клиентом (игра на виртуальные очки). Для реальных денег нужен серверный расчёт раундов и защита от повторов — это отдельный этап.

## Ограничения бесплатного Supabase

- 500 МБ базы, бесплатные Edge Functions.
- Проект может уснуть после недели без активности — будится в dashboard.
